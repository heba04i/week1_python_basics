# Week 1 Python Basics

This project contains basic Python scripts for learning fundamentals.

## Files included:

- word_counter.py → counts word frequency from a text file
- stats_calculator.py → calculates min, max, average, median
- list_cleaner.py → removes duplicates and sorts a list
- simple_cli_tool.py → simple user input program

## How to run:

Open terminal and run:

python filename.py
